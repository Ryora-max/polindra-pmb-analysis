- **Tidak ada kaitan institusional dengan SAP/konsultan ERP** — mitra IT-nya Integrasia (IoT), SEVIMA (SIAKAD), Racer Robot (robotika).
- Cirebon Power/PLTU: tidak ada MoU terverifikasi dengan Polindra.
- Alumni terverifikasi bekerja di Pertamina EP Jatibarang, Kaldu Sari Nabati (staff SAP ERP!), Radiant Utama, via jalur RECARE → Pupuk Kaltim/Freeport/PIM.
